# Agent guide — Wiki/30_People

Who does what: roles, onboarding, and the **advisor factory**.

When working here:
- Each **role** note states a single clear mandate and the playbooks it owns.
- [[Onboarding]] is the first thing a new hire reads — keep it to the first 14 days.
- Never put performance details or sensitive personal data in the brain. Roles and mandates only.
- **Advisors:** [[_advisor_template]] is the schema for any advisor; [[_advisor_router]] maps decision types to advisors. Build new ones with `/build-advisor`; invoke one with `/advisor <name> <topic>`.
