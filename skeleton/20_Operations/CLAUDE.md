# Agent guide — 20_Operations

This folder holds how we actually run: playbooks, SOPs, and vendor notes.

When working here:
- A **playbook** must be runnable by a new hire with no supervision — concrete numbered steps, not principles.
- Link each playbook to the [[Role - Founder CEO]] who owns it and to any [[Vendor Notes]] it depends on.
- When a process changes because of a decision, link the relevant note in [[Decision Log]].
- Keep [[Vendor Notes]] current; an outdated vendor list is worse than none.
