# Agent guide — 00_Company

This folder holds the company's identity: mission, structure, and shared language.

When working here:
- Treat [[Mission and Vision]] as the source of truth for *why we exist*. Don't contradict it.
- Keep [[Glossary]] authoritative: if a term is used elsewhere, define it here.
- [[Company Structure]] should always reflect the current your team-person org. If a role changes, update it and link the affected [[Role - Founder CEO]] note.
- This folder is mostly stable. Prefer adding to it over rewriting it.
